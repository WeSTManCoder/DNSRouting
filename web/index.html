DNS-серверы

Резолверы и приоритеты
Один HTTPS-адрес в строке, в порядке приоритета. Применяются как к маршрутизируемым доменам, так и к доменам «только DoH». При отсутствии DNS-записей пробуется следующий сервер.
Один сервер в строке. Порядок строк задаёт приоритет: сначала первый, затем следующий при отсутствии ответа с записями.
Поддерживаемые адреса: https://dns.google, https://dns.google/dns-query, 8.8.8.8, udp://8.8.8.8, udp://8.8.8.8:53.

Правила маршрутизации

Файл services.txt
Одно правило в строке. Используются существующие правила сопоставления доменов DNSRouting. Изменение списка при сохранении запускает сброс DNS-кеша.

Только DoH — без маршрутизации

Файл doh-only.txt
Для этих доменов используется основной список DoH, но IP-адреса НЕ добавляются в VPN-маршруты. Если домен совпал с обоими списками, приоритет имеет раздел «Маршрутизация».
Правила — регулярные выражения. Для конкретного домена используйте ^example\.com$, для домена и поддоменов — (^|\.)example\.com$.
